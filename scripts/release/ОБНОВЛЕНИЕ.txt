ТАРО — ОБНОВЛЕНИЕ

Это небольшой архив обновления, а не полная установка.
Он заменяет только файлы программы. Папка data с вашими записями не трогается.

1. Закройте служебное окно Таро — то, где написано «не закрывайте».
2. Откройте папку «Таро» и распакуйте этот архив прямо в неё.
   Если архиватор создал внутри ещё одну папку, перенесите её содержимое
   в папку «Таро» и разрешите заменить файлы.
3. Дважды щёлкните:
   • macOS и Linux — «Обновить Таро.command»
   • Windows — «Обновить Таро.bat»
4. Скрипт сам сделает резервную копию базы в data/backups,
   заменит файлы и запустит новую версию.

Если система предупредит о неизвестном разработчике:
macOS — правый клик по файлу → «Открыть» → «Открыть».
Windows — «Подробнее» → «Выполнить всё равно».

Если что-то пошло не так, записи в папке data останутся на месте.
Напишите на tarot.feedback@mail.ru и приложите фотографию экрана.
