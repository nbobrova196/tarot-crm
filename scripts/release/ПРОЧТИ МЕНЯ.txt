ТАРО — КАК ЗАПУСТИТЬ

1. Распакуйте архив в удобную папку, например в «Документы».
2. Откройте папку «Таро».
3. Дважды щёлкните по ярлыку:
   • macOS — «Запустить Таро.command»
   • Windows — «Запустить Таро.bat»
4. Через пару секунд откроется браузер с приложением.
   Если браузер не открылся, зайдите по адресу: http://localhost:3000

Чтобы остановить приложение, просто закройте чёрное окно терминала.
Ничего устанавливать не нужно: Node.js уже лежит внутри папки.


ЕСЛИ macOS НЕ ЗАПУСКАЕТ ЯРЛЫК

Нажмите на «Запустить Таро.command» правой кнопкой мыши → «Открыть» → «Открыть».
Если и это не помогло: «Системные настройки» → «Конфиденциальность и безопасность»
→ прокрутите вниз и нажмите «Всё равно открыть» рядом с предупреждением про Таро.

Это обычное предупреждение macOS для программ не из App Store. Оно появляется
один раз, при следующих запусках его не будет.


ЕСЛИ WINDOWS ПРЕДУПРЕЖДАЕТ

Нажмите «Подробнее» → «Выполнить всё равно».
Это стандартное предупреждение SmartScreen для новых программ.


ГДЕ ХРАНЯТСЯ ДАННЫЕ

Все расклады, клиенты, заметки и карты дня лежат в папке data внутри папки «Таро».
Чтобы сделать резервную копию, скопируйте папку data в надёжное место.
При обновлении программы заменяйте все файлы, кроме папки data.


ЕСЛИ ПОРТ 3000 УЖЕ ЗАНЯТ

Приложение само выберет следующий свободный порт и напишет адрес в окне.
Просто откройте тот адрес, который показан.


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

Напишите в разделе «Сообщения разработчику» внутри приложения или создайте
issue в репозитории на GitHub. Приложите текст из чёрного окна — он поможет
быстрее разобраться.
