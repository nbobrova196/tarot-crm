ТАРО — КАК ЗАПУСТИТЬ

1. Распакуйте архив в удобную папку, например в «Документы».
2. Откройте папку «Таро».
3. Дважды щёлкните файл запуска:
   • macOS и Linux — «Запустить Таро.command»
   • Windows — «Запустить Таро.bat»
4. Через несколько секунд откроется браузер с приложением.

Откроется чёрное служебное окно. Не закрывайте его, пока работаете:
это не установка и не ошибка. Чтобы остановить программу, закройте это окно.

Ничего устанавливать не нужно: Node.js уже лежит внутри папки.


ЕСЛИ СИСТЕМА ПРЕДУПРЕЖДАЕТ

macOS: нажмите на файл запуска правой кнопкой → «Открыть» → «Открыть».
Если предупреждение осталось: «Системные настройки» → «Конфиденциальность
и безопасность» → прокрутите вниз → «Всё равно открыть».

Windows: «Подробнее» → «Выполнить всё равно».

Это обычное предупреждение для программ не из App Store. Оно появляется
один раз, при следующих запусках его не будет.


ЕСЛИ БРАУЗЕР НЕ ОТКРЫЛСЯ

Подождите несколько секунд. Потом откройте Safari, Chrome или Edge и введите:
http://localhost:3000

Если страница не открывается, посмотрите на чёрное окно: там написан адрес.
Если и там пусто — закройте окно и запустите файл ещё раз.


ГДЕ ЛЕЖАТ ДАННЫЕ

В папке «Таро» есть папка data. Внутри — файл tarot.db со всеми записями.
Не удаляйте и не переименовывайте папку data.

Для резервной копии нажмите «Резервная копия» в боковом меню приложения.
Копии сохраняются в data/backups.

При обновлении замените все файлы, кроме папки data.


ЕСЛИ НИЧЕГО НЕ ПОЛУЧАЕТСЯ

Напишите на tarot.feedback@mail.ru — опишите, что произошло, и приложите
фотографию экрана. Разберёмся.
